# Dependencias de terceros

- **Tesseract.js 6.0.1** — motor OCR JavaScript/WebAssembly, licencia Apache-2.0. Proyecto: https://github.com/naptha/tesseract.js
- **Tesseract.js Core 6.0.0** — motor OCR WebAssembly, licencia Apache-2.0. Proyecto: https://github.com/naptha/tesseract.js-core
- **English `tessdata_fast` model** — modelo de idioma para Tesseract, licencia Apache-2.0. Proyecto: https://github.com/tesseract-ocr/tessdata_fast

Los archivos necesarios se distribuyen localmente dentro de `assets`; no se utiliza una API OCR ni se envían las fotografías a un servidor.
